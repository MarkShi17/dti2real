# DTI2IRL implementation plan

**Goal:** Deliver the full screenshot → editable garments → product selection → wardrobe → pose → export workflow locally, with truthful demo and live providers.

**Spec:** `SPEC.md` (complete copy of the supplied `DTI2IRL_Codex_MVP_Spec.md`).

**Architecture:** Next.js App Router and TypeScript. React context owns the workbench; typed server providers own integration boundaries. Filesystem storage is private, session scoped, and expires after 24 hours. Requests use an HttpOnly session cookie; no photos in localStorage. Server-side jobs persist statuses and cache intermediate garment renders.

**Execution:** Native implementation using executing-plans, with final independent review. User explicitly authorized independent decisions and full implementation, so no additional design gates. Clean directory has no existing Git repository; implement in place without inventing branch history.

**Visual system:** Charcoal #18171b, panel #222126, off-white #f5f0e8, pink #f5a6d3, muted #b3adb8, lilac #c6b5ec. Georgia italic editorial display paired with system sans; large fashion images anchor a three-column workbench. Mobile steps have a sticky action. Colors follow the user's spec; interface chrome stays quiet.

## Global constraints
- No fabricated live listings, prices, stock, or generations.
- No Roblox or Depop scraping; all external services behind typed providers.
- US/USD; local first; no rented infrastructure or paid calls without configured credentials.
- Photos require consent, remain private, and are deletable. Remote images require SSRF-safe fetching.
- Demo assets are synthetic adults and visibly marked sample previews.

## Review focus
- A changed garment/person/pose must never present an old render as a current result.
- Missing provider keys and partial failures must remain actionable without silent demo fallback.
- Unpriced/foreign-currency listings must not pass a USD cap; unknown condition must not pass secondhand.
- Cross-session IDs and malicious URLs must not disclose images or permit internal-network requests.
- Delayed search/job responses after edits or deletion must not restore stale state.
