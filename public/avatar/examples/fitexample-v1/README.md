# fitexample-v1

Approved offline demo fixture. `avatar.glb` combines the local CC0 MakeHuman-based studio rig with authored mesh geometry for the green asymmetrical sweater, navy wide trousers, burgundy crossbody, taupe flats, and brown chin bob. The reference image informed silhouette and palette only; it is not embedded or projected onto the mesh.

Rebuild with `node scripts/package-example-avatar.mjs`. `SOURCES.json` records the resulting file checksum and provenance.
